# Session 1 — Проект «ГРАММ»

## Исходный промт пользователя
> Сделай простой сайт для спорта и питания, где я смогу добавлять ингредиенты и их
> количество, а сайт автоматически рассчитывает калории и БЖУ. Также добавь возможность
> создавать рецепты из ингредиентов и подбирать блюда под заданные мной бжу— можно один
> index.html без сборки.
> Данные храни в localStorage. Дай мне запустить его локально.

## Что это
Одностраничное веб-приложение (`index.html`, без сборки) для учёта питания спортсмена:
калькулятор калорий и БЖУ, база ингредиентов, конструктор рецептов, подбор блюд под
заданные целевые БЖУ. Интерфейс на русском языке.

## Технический стек
- Чистый HTML + CSS + JavaScript, один файл `index.html`
- Без фреймворков и сборки — открывается напрямую в браузере
- Хранение данных: `localStorage` браузера (ключи `gramm_ingredients`, `gramm_recipes`, `gramm_calc_items`)
- Шрифты: Space Grotesk (заголовки), Inter (текст), IBM Plex Mono (числовые значения)

## Функциональность
1. **Калькулятор порции** — выбор ингредиента + граммовка → автоматический подсчёт
   ккал/белков/жиров/углеводов, визуализация макро-пропорций (цветная полоса).
2. **База ингредиентов** — 20 предзагруженных продуктов (на 100 г), добавление,
   редактирование, удаление своих ингредиентов.
3. **Рецепты** — сохранение набора ингредиентов из калькулятора как именованного рецепта;
   значения пересчитываются автоматически при изменении базы ингредиентов.
4. **Подбор блюд** — ввод целевых ккал/Б/Ж/У → список сохранённых рецептов,
   отсортированный по близости к цели (с процентом совпадения).

## Дизайн
Палитра «лабораторный блокнот»: тёплый пергамент (#F5F3EC) + чернильный тёмный сайдбар,
три акцентных цвета для макронутриентов (белки — терракота, жиры — охра, углеводы —
зелёный) и синий для калорий. Моноширинный шрифт для чисел — акцент на точности.

## Файлы сессии
- `index.html` — готовое рабочее приложение (передано пользователю)

Приложение полностью рабочее, протестирован синтаксис JS. Ожидает обратной связи
пользователя по функциональности/дизайну для дальнейших доработок.
