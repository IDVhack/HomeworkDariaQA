## Готово

Одностраничное приложение «ГРАММ» (`index.html`): калькулятор порции, база
ингредиентов, рецепты, подбор блюд под БЖУ — базовый функционал работает
(см. `sessions/session-1.md`).

В сессии 2 проведено ручное тестирование по `SPEC.md`, найденные дефекты
зафиксированы в `BUGS.md` (код не правился — роль была «тестировщик»).

В сессии 3 добавлена новая функциональность (код правился впервые):
- Поиск ингредиента с выпадающим списком (комбобокс) в блоке «Добавить
  ингредиент» на вкладке «Калькулятор» — вместо плоского `<select>`.
- Необязательное поле «Вес 1 шт, г» при создании/редактировании ингредиента
  (вкладка «База ингредиентов»), отображается отдельным столбцом в таблице.
- Переключатель единиц «г / шт» при добавлении ингредиента в порцию/рецепт;
  «шт» переводится в граммы через заданный вес одной штуки. Опция «шт»
  задизейблена, если у ингредиента штучный вес не задан.

## Активные инструменты

Чистый HTML/CSS/JS без сборки (само приложение — по-прежнему без изменений).
Для проверки использовались `python3 -m http.server`, Playwright/Chromium и
Pillow (для аннотации скриншотов красной рамкой) — доступны в окружении,
отдельно не устанавливались как зависимость проекта. Появился первый
формальный тестовый инструментарий: `package.json` + `tests/` в корне
проекта, зависимость `playwright` (Node) для автотестов. `@playwright/test`
недоступен для установки в этой среде (см. `TOOLS.md`).

## Известные проблемы

- См. `BUGS.md`:
  - `[minor]` длинное название ингредиента ломает вёрстку таблицы базы
    (сессия 2, не исправлено).
  - `[minor]` подпись опции «шт» округляет дробный вес одной штуки до целого
    (сессия 4, не исправлено).
  - `[major]` на экранах ≤480px и калькулятор, и вкладка «Ингредиенты» не
    вписываются в ширину экрана — нужен горизонтальный скролл/масштабирование
    (сессия 4, не исправлено) — самый широкий по охвату из известных на
    сейчас дефектов.
- Открытый вопрос в `SPEC.md`: нужна ли явная подсказка/подсветка, когда
  пользователь вводит текст в поиске ингредиента, но не выбирает пункт из
  списка, и нажимает «Добавить» (сейчас — молчаливый возврат фокуса).
- Новые поля (`pieceGrams`) не заполнены у ингредиентов по умолчанию — для
  них опция «шт» недоступна, пока пользователь не впишет вес вручную.
